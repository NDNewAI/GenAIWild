Claude Maker Recipes

In Week 6 you met Cowork and Claude Code, and in Weeks 7 and 8 you used Cowork to set up a research database that keeps itself up to date. Now it is your turn to build something of your own. Pick something you are not sure can be done, aim at it with Cowork or Claude Code, and document how far you got and where it broke.

New to Claude Code, or have you only used Cowork? Start with From Cowork to Code: An Introduction and Practice, then come back and pick a recipe.

Why think bigger

As we discussed in our last class focused on Claude, there is an opportunity to move from LLMs as chatbots to Agents as makers, but your imagination is probably the biggest limit. To help you think about new opportunities and start to work toward the final project, we provide these recipes as potential starting points for the Agentic Maker Project. The idea is to use these for ideas, experiments and starting points but push beyond them for the final project.

Every recipe below is a starting point. Each one tells you what to say to Claude, what Claude will probably do and how to push the result further. Most also suggest how to go much bigger. The recipes are grouped by college and major, but you are welcome to cook from any section.

What Claude and nearby tools can do now

Prof. Smiley's Week 6 visit covered the basics. This list adds what is most useful for this project, current as of November 7, 2026. Which features you see depends on your account and your app version, so if a feature is missing, ask us about it. It does not mean you did something wrong.

The models

The four models from Prof. Smiley's slides are current: Haiku, Sonnet and Opus are all version 5.5, released between September 22 and October 7. His advice still holds. Use Sonnet by default, use Opus when a task really needs it, and do not use Fable on our plan.

Cowork builds more than files

Besides the files you used for your research database, Cowork can build editable documents, slide decks, spreadsheets, designs, whiteboards, dashboards and short animations. Each opens in an editor you can change yourself and exports to Word, PowerPoint, PDF or images.

Artifacts are live pages

An artifact is a web page Claude publishes for you, with its own private link. Depending on your account, it can keep data that all its viewers share, ask Claude a question while someone uses it, and sometimes use a phone's camera, microphone or motion sensors.

Teams of agents

Claude Code can split a job among several helper agents that work at the same time, each with its own role, and it can run work on a schedule. Teams count against your usage limits quickly, so start with two or three agents. See the Claude Code changelog for details.

Claude in the browser and on your desktop

Claude can read and work through websites in Chrome or in the Claude desktop app's own browser, and it can operate desktop applications by looking at the screen. It asks before anything consequential, such as submitting, sending or buying.

Skills travel with you

The skills Prof. Smiley showed you follow a shared format. On October 22, Anthropic gave that format to the Agentic AI Foundation, and more than 70 platforms had adopted it, so a skill you write for this class can work elsewhere. See Anthropic's announcement.

3D models and worlds from a prompt

Meshy, Tripo and Hunyuan 3D turn text or photos into 3D models and have free tiers, and Microsoft's TRELLIS.2 is open source (comparison, checked September 2026). World Labs' Marble has a free tier that turns a prompt or photo into a whole scene you can walk through (world-model comparison).

Agents that check agents

You can have one agent do the work and a second agent score it against a rubric you write, sending it back if it falls short. If this sounds like ECD, it is: the rubric holds your claims and evidence, and the second agent is an evaluation you can inspect.

Ground rules and how big to go

Most of these rules carry over from the research database steps in Week 7. The ladder on the right is a way to choose your ambition on purpose.

  1. Start every piece of work in plan mode. Read the plan, change it, then approve it. In Cowork, ask Claude to show you its plan before it acts.
  2. Give Claude one new folder and nothing else. Do not give it your Documents or Downloads folder. Claude Code also has a setting that blocks file writes outside your working folders in every permission mode; ask Claude to help you turn it on.
  3. Keep keys out of the chat. When a recipe needs an API key, put it in a file named .env in your project folder and tell Claude to read it from there. Never include a key in anything you submit.
  4. Installing open-source software is encouraged, as long as you know what you are installing. Before Claude installs anything, ask it to tell you what the software is, where it comes from, how much disk space it needs and how to remove it later. Ask Claude to install into your project folder (for Python, a virtual environment) so that deleting the folder removes the software too. Install only from official sources, as you did with Obsidian in Week 7. Check your machine first: most recipes run on any Mac or Windows laptop from the last few years, but running AI models locally needs at least 8 GB of memory, 16 GB is much better, and the downloads can take several gigabytes of disk space. Chromebooks and iPads will not work. Plug in your laptop, because heavy jobs drain the battery and run the fans.
  5. Keep the web read-only. Let Claude gather and compare. Do any submitting, sending, applying or buying yourself.
  6. Respect other courses. The syllabus asks that class materials not be shared with AI systems without permission. Use your own notes and public sources.
  7. Watch your usage limits. Agent teams and scheduled runs count against your usage limits much faster than a single chat. Start with two or three agents and a schedule of once a day or less.

Data sources were checked in early November 2026. Public APIs change. If a recipe's data source has moved, that is worth noting, and Claude can usually help you find its replacement.
